Agent mascot: mood states

Every mood uses the same four parts: the four lobes (from the logo), the eyes, the base line and color. Pick a mood in the playground to see how one state changes into another. All moods are built from the same shape, so the mascot can move between any two of them smoothly.

Lobes: breathe, ripple, pump, sag, tense, or split back into the four logo dots.
Eyes: the main emotion carrier. They can be pills, arcs, slants, closed curves, or one shared visor.
Base line: a shadow, a smile or frown, or a progress bar.
Color: brand purple by default; pastel for sad, navy for mad, grey for sleep.
Extras: small effects only where they add meaning (thought dots, pings, sparkles, z's).
